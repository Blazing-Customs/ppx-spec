# Community

PPX is a young, draft-stage specification. Contributions are welcome.

## Where work happens

- **Spec repo:** [Blazing-Customs/ppx-spec](https://github.com/Blazing-Customs/ppx-spec)
- **Reference provider:** [Blazing-Customs/ppx-provider](https://github.com/Blazing-Customs/ppx-provider)
- **Issues / discussions:** in the spec repo.

## How to contribute

- **Open an issue** to discuss a change before writing a PR for anything
  non-trivial.
- **Use the [proposal template](governance/proposal-template.md)** for
  substantive changes (new namespaces, binding targets, breaking changes).
- **Follow the [versioning policy](governance/versioning.md)** when bumping
  the spec or schemas.
- **Run the [conformance suite](https://github.com/Blazing-Customs/ppx-spec/tree/main/conformance)**
  before claiming compliance.

## Working groups (future)

Once PPX adoption grows, we expect to form lightweight working groups along
the lines of:

- **Core schema** — the base data model.
- **Trust & consent** — the consent/grant model, cross-domain semantics.
- **Domain vocabularies** — fragrance, travel, media, commerce, etc.

For now, discussion happens in the spec repo.
